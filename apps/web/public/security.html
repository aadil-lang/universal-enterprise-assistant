Part 5 • Security & Production Engineering Decisions

Security Boundaries & Adversarial Protections

Defense-in-depth safeguards protecting employee privacy, preventing prompt injection, and eliminating data mutation risks.

01

Read-Only FastMCP Boundaries

The Model Context Protocol integration strictly exposes 4 read-only employee database functions. The assistant possesses zero tools to create, update, or delete records.

• get_employee_profile
• get_employee_leave_balances
• get_employee_assigned_assets
• get_employee_it_tickets
02

Employee Peer Record Isolation

Every tool invocation evaluates the caller's JWT claims. Regular employees cannot view peer records; attempts to query colleagues return HTTP 403 / Access Denied.

Bob (E102) ➔ Query Carol (E103)
➔ BLOCKED by MCP Client
HR Admin (E101) ➔ Allowed (Audited)
03

Adversarial Injection Defense

Input guardrails intercept "ignore previous instructions", system prompt leak attempts, and secret harvesting prior to state machine execution.

• 14/14 Adversarial Tests Passed
• XML-Isolated Untrusted Policy Text
• Zero Internal Prompt Disclosures
04

HMAC Service Authentication

Internal HTTP calls between FastAPI and FastMCP are signed using HMAC-SHA256 headers with epoch replay protection, blocking lateral network tampering.

X-Acme-Timestamp: 1795353600
X-Acme-Signature: sha256=9f83...
Replay Window: 30 seconds
05

HttpOnly Cookie Transport

JWT access tokens are issued as HttpOnly, SameSite=Lax cookies, completely eliminating client-side token exposure to malicious JavaScript or XSS vectors.

Set-Cookie: acme_access_token=...
HttpOnly; SameSite=Lax; Path=/
Strict Content Security Policy
06

Active-Version Citation Grounding

Every retrieved vector chunk is verified against the PostgreSQL active checksum pointer. Inactive or superseded policy versions are discarded automatically.

• Document Registry Integrity
• 100% Citation Grounding
• Zero Untracked Hallucinations
